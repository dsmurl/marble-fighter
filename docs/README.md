# Documentation

Project documentation for **Marble Fighter**, an all-code 3D marble battle prototype built with
TypeScript, Vite, Babylon.js, and Havok physics. This directory is the home for everything that
isn't source code or the top-level `README.md`: how the system is put together, how to get it
running, how to perform day-to-day tasks around the repo, and how it's tested. Start with
[setup/](setup/README.md) if you just want to run the game locally.
